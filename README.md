**Learn Git Simply** is a short, friendly Git guide in 3 chapters, with a quiz in each one.

**Learn Git Simply** est un guide Git court et simple en 3 chapitres, avec un quiz dans chacun.

1. Les bases
2. Au-delà des bases
3. Les outils avancés
